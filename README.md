# 🏸 羽球接龍大廳 — 使用者說明

> 本文件適用對象：**所有群組成員**
> 管理員操作說明請見 → [ADMIN_GUIDE.md](./ADMIN_GUIDE.md)

---

## 我要怎麼報名？

### 步驟

1. 點擊群組中的 **「羽球接龍大廳」連結**
2. 在大廳看到所有場次卡片
3. 點擊想參加的場次，進入報名頁面
4. 點擊 **`[+1]`** 即可用您的 LINE 名稱報名 ✅

就這麼簡單！不需要在群組裡輸入任何文字。

---

## 幫朋友代報（代報名）

1. 進入場次詳情頁面
2. 在底部的 **「姓名」** 欄位輸入朋友的名字
3. 點擊 **`[+1]`** 送出

> 代報的名字，**所有人都可以幫忙取消**（因為不確定是誰幫忙報的）。

---

## 取消報名

### 取消自己的報名

1. 進入場次詳情頁面
2. 找到自己的名字，點旁邊的 **`❌`** 按鈕
3. 確認後即可取消

### 取消代報的名字

- 代報名稱（非本人的名字）旁邊的 `❌` 按鈕**任何人都可以點**
- 自己的名字只有自己才能刪除

---

## 查看名單

進入場次詳情後，可以看到：

| 區塊 | 說明 |
|------|------|
| **報名名單** | 正取的成員，依序編號 |
| **候補名單** | 等待遞補的成員 |
| **已報名** | 您自己報名的名字旁邊會特別標示 |

---

## 繳費狀態

- 已繳費的名字旁邊會顯示 **「💰 已繳費」** 標記
- 一般用戶**無法修改**繳費狀態（由管理員操作）

---

## 候補如何遞補？

正取名單有人取消後，系統會**自動遞補**候補名單中的第一位，並在群組發送通知訊息。

---

## 常見問題

**Q：我在群組打 +1 會有反應嗎？**
A：不會。請使用大廳連結報名，機器人不理會一般文字訊息。

**Q：我點 +1 說「您已經報名過了」？**
A：您的名字已在名單中了，不能重複報名。

**Q：我點 ❌ 說「只能取消自己或自己代報的名單」？**
A：您只能取消自己的名字，或者您親自代報的名字。其他人的自報名單不能被他人刪除。

**Q：名額滿了怎麼辦？**
A：`[+1]` 按鈕會變成灰色無法點擊，名單已額滿。如有候補名額，您可以在候補欄位報名等待遞補。

**Q：不知道大廳連結在哪？**
A：聯絡管理員在群組輸入 `接龍大廳`，機器人會重新推送連結。
