# LINE 羽球接龍機器人 V2.0

這是一個專為 LINE 群組打造的羽球接龍管理機器人 V2.0，全面升級為「LIFF 網頁大廳」報名模式，並具備嚴格的「管理員權限防護」，確保群組不受機器人洗版，且名單管理安全不手誤。

## 🌟 V2.0 全新亮點

1. **全面採用 LIFF 網頁大廳**：
   - 告別過去在群組內 +1 洗版的困擾！
   - 所有報名、取消、查看名單的操作，皆在精緻的網頁 UI 中完成。
   - 支援顯示「日期」、「時間」、「地點」、「費用」等清楚的資訊方塊。
2. **管理員專屬權限**：
   - 只有透過通關密語升級為「管理員」的人，才能對機器人下達文字指令（如建立場次、結束場次）。
   - 其他群友輸入指令，機器人將一律「已讀不回」，徹底防範亂下指令。
3. **即時防呆與取消保護**：
   - 網頁介面即時檢查「名稱是否重複」或「找不到名稱」。
   - **防誤刪機制**：只有幫該名稱報名的人（或本人）才有權限取消報名，防止惡意或手誤取消他人名單。
4. **貼心狀態顯示**：
   - 進入名單明細，若您（或您代報的人）已在名單中，會貼心顯示 `(已報名)`。

---

## 👑 管理員權限開通

在群組內輸入以下通關密語，即可成為該群組的管理員：
```text
接龍密碼 Tony好帥
```
機器人會回覆：「✅ 權限已開通！您現在是本群組的管理員了。」

> ⚠️ **注意**：只有取得管理員身分的人，機器人才會回應下方的文字指令。一般群友請直接點擊大廳網址進行報名。

---

## 📝 管理員專用文字指令

### 1. 建立場次 (接龍開始)
在群組內輸入 `接龍開始` 並加上欄位資訊。系統會自動在網頁大廳建立精緻的卡片。

**格式範例：**
```text
接龍開始
日期：星期二
時間：晚6~8
地點：南港運動中心
費用：230
人數：20
候補：5
名單：小明, 小華
備註：新手友善，請自備零錢
```

**支援欄位說明：**
- `標題：`（選填，若無填寫則自動組合日期時間地點作為標題）
- `日期：`（選填，如：星期二）
- `時間：`（選填，如：晚6~8）
- `地點：`（選填，如：南港運動中心）
- `費用：`（選填，如：230）
- `人數：`（正取名額，預設 20）
- `候補：`（候補名額，預設 5）
- `名單：`（預先帶入的名單，用逗號或空白分隔）
- `備註：`（顯示於大廳卡片下方）

建立成功後，機器人會在群組發布「大廳連結」，大家點進去就能開始報名！

### 2. 修改場次 (接龍修改)
若要修改特定場次的資訊，可加上「關鍵字」指定要修改哪一天的場次。

**格式範例：**
```text
接龍修改 星期二 人數：25
接龍修改 星期四 地點：玉成國小
接龍修改 南港 備註：改成自備羽球
```
機器人會尋找包含該關鍵字的場次並自動更新。

### 3. 結束/清空場次
- `接龍結束 星期二`：關閉並移除標題包含「星期二」的場次。
- `接龍清空`：一鍵刪除群組內所有的場次。

### 4. 呼叫大廳
- `接龍大廳`：機器人會再次發送大廳的專屬連結到群組中，方便大家找網址。

## 🏸 一般群友如何報名？

一般使用者**不需要**輸入任何文字指令。

1. 點擊群組內的**「羽球接龍大廳」網址**。
2. 進入大廳後，選擇想打球的場次。
3. 點擊卡片上的 `[+1]` 即可以自己的 LINE 名稱報名。
4. 若要幫朋友代報，只要在 `[輸入名稱]` 框框內打字，再點擊 `[+1]` 即可。
5. 取消同理，點擊 `[-1]` 即可取消本人報名，或在框框內輸入朋友名字後點擊 `[-1]` 來取消代報。

> **防護機制**：
> 系統嚴格規定，如果您沒有幫「小明」報名，您就無法點擊 `-1` 取消小明的位置！會跳出紅字錯誤保護名單安全。
